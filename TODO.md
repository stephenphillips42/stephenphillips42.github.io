# Game description
A number appears under the cursor that appears only when you are over the hidden button, that increments when you click (0 -> 1 -> 2) then the button moves and you go to the slightly highlighted place and try clicking again. If you wait too long between clicks, the number will go down. There will be a color animation on the number going from yellow to red to indicate the amount of time you have left.
